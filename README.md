# Навигатор покупок — комплект обновления

В архиве подготовлен демонстрационный редизайн сайта:
- `index.html` — главная страница с картой магазина и построением примерного маршрута;
- `catalog.html` — отдельная страница каталога с карточками, изображениями, поиском и фильтрами;
- `styles.css` — адаптивное оформление;
- `app.js` — интерактивность карты и демонстрационного маршрута;
- `catalog.js` — демонстрационный каталог и импорт CSV;
- `products-template.csv` — шаблон таблицы товаров.

## Как опубликовать
1. Скачайте архив и распакуйте его.
2. Откройте репозиторий `vmf72vvf65-oss/-` на GitHub.
3. Замените `index.html` и загрузите остальные файлы в корень репозитория.
4. Сделайте Commit changes. GitHub Pages опубликует обновление автоматически.

## Импорт из Excel
Откройте `products-template.csv` в Excel, заполните строки и сохраните как CSV UTF-8. На странице каталога нажмите выбор CSV-файла.
Заголовки колонок: `id,name,category,brand,size,price,zone,image`.
Для дальнейшего точного маршрута понадобятся также координаты зоны/стеллажа и таблица времени переходов. Их можно добавить отдельными листами Excel на следующем этапе.

## Важно
Содержимое каталога, цены, фотографии и схема — демонстрационные. Время и расстояние маршрута пока не рассчитываются. CSV-импорт работает в браузере и не сохраняет изменения в репозитории или на сервере.
